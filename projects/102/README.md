# QinQ基本组网配置举例

## 需求：

两个分支机构Site 1和Site 2通过运营商网络进行通信，PE 1和PE
2为运营商网络的边缘设备，且二者通过TPID值为0x8200的运营商网络设备进行连接，Site
1和Site 2需要利用运营商提供的VLAN 100使公司A的两个分支机构之间实现互通。

##  实验步骤：

1.  在PE设备上进行qinq配置；

2.  PE连接运营商侧接口配置外层vlan tag的TPID值。

## 测试结果：

CE1和CE2之间可以互访

![](./Media//image1.png)


## 说明： 

1、本实验用的模拟器为S6850，设置内存为默认。

2、本实验用的交换机版本为默认版本。
