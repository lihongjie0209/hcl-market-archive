# 即插即用网关基本组网配置举例

## 需求：

-   PC-1的IP地址是172.16.0.1/16，所在局域网的网络号为172.16.0.0/16。

-   PC-2的IP地址是172.16.1.1/16，所在局域网的网络号为172.16.0.0/16。

-   PC-1和PC-2互相认为处于同一子网，但实际却被设备Router分在两个不同的子网。

-   PC-1和PC-2没有配置缺省网关，要求在设备Router上开启普通代理ARP功能，使处在两个子网的PC-1和PC-2能互通。

## 实验步骤：

1.  配置IP地址。

2.  Router两个接口开启普通ARP代理，命令为proxy-arp enable。

## 测试结果：

配置完成后，PC-1和PC-2可以互相ping通。

![](./Media//image2.png)


## 说明： 

1、本实验用的模拟器为MSR36-20，设置内存为默认。

2、本实验用的路由器版本为默认。
