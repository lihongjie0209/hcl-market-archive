**需求：**

NAT穿越模式下（分支侧穿越），IPSEC主模式，分支使用对等体，总部使用对等体FQDN认证建立IPSEC
VPN。

**实验步骤：**

1、设置F1060_4作为分支侧出口设备、F1060_5为总部侧VPN网关设备；MSR3620_2分支侧的出口NAT设备，MSR3620_1和MSR3620_3为公网上的转发设备。需要将F1060_4和F1060_5的路由打通（即分支的VPN出口地址3.3.3.1和总的出口地址5.5.5.1）。

测试结果：

两端的兴趣流使用设备上的lopback口，分支侧为10.10.10.10；总部侧为10.10.20.10。

**说明：**

1.  本实验使用的设备中默认防火墙作为VPN的网关，为了减小实验的难度，安全策略方面为全放通策略；

2.  实验中使用的本端和对端身份认证都是FQDN的形式，要求两侧的认证名字是可知的，这样即可避免分支侧NAT以后的公网地址不清楚时候的认证失败；

3、配置ipsec
vpn的忌讳在于兴趣流冲突，使用的transform和proposal和别的ipsec隧道之间有冲突的。即相同的transform和proposal配置一次，被不同分支调用即可。
