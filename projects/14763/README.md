# 工程名称

静态路由实现网络连通

## 需求：
需要SWA能够访问SWC上的环回口地址


## 实验步骤：
1.配置各接口ip地址。
2.在SWA上配置静态路由访问SWC的环回地址的下一跳为SWB的10.1.1.2
3.在SWB上配置静态路由访问SWC的环回地址的下一跳为SWC的20.1.1.2
4.在swc上配置静态路由访问SWA的10.1.1.1的下一跳为SWB的20.1.1.1
5.测试连通性

## 测试结果：
以SWB为例，发现未配置静态路由时，查不到访问1.1.1.1地址的路由，配置后可以正常查到
