**标签：**

攻击防范

泛洪攻击

安全策略

**需求：**

内网网关地址为10.10.10.2/24，在出口部署一台防火墙用于保护内网服务器，防火墙内网口G1/0/2地址为10.10.10.1，外网口G1/0/1地址为116.1.1.1/24，用一台Host模拟公网主机（116.1.1.2），在防火墙上配置攻击防范策略保护内网服务器避免受到公网主机的攻击。

**实验步骤：**

1、组网搭建

根据组网图搭建环境，使用一台Host模拟Attacker，Host绑定PC虚拟网卡，配置IP地址116.1.1.2/24，网关为116.1.1.1。使用一台MSR作为内网网关，配置GE0/2的地址为10.10.10.2/24，并配置缺省路由下一跳为10.10.10.1。同时注意配置PC上的路由。

![](./Media//image1.png)


2、配置攻击防范

配置防火墙的内外网接口IP地址，并将外网口G1/0/1和内网口G1/0/2分别加入Untrust和Trust安全域，并放通相应安全策略。

在导航栏中选择"策略\>安全防护\>攻击防范"，新建攻击防范策略，并进入攻击防范策略配置视图。进入泛洪防范公共配置页签，修改ICMP的门限值为1（表示每秒一个包），勾选日志、检测所有IP地址和丢包，将策略应用于Untrust域。

![](./Media//image2.png)


切换到"知名单包攻击防范"，配置超大ICMP报文攻击门限值为1000，勾选日志和丢包。完成所有配置后，点击\<确定\>。

![](./Media//image3.png)


**测试结果：**

下载科来ping工具（http://www.colasoft.com.cn/download/capsa_tool_ping.php），安装运行后，点击设置，设置两次ping间时延为100ms，可以测试ICMP泛洪攻击防护。

从客户端向内网网关10.10.10.2发起ping测试，在导航栏"监控\>安全日志\>泛洪攻击日志"中，可以看到在防火墙上生成泛洪攻击日志。

![](./Media//image4.png)


客户端可以看到部分报文ping请求超时，说明ping包触发防火墙的攻击防范策略，超过了每秒1个，超过部分被丢弃。据此可以验证攻击防范配置生效。

![](./Media//image5.png)


在科来工具上恢复缺省值，设置发送包大小为1024字节。可以测试ICMP超大包攻击防护。

![](./Media//image6.png)


同样地，从客户端向内网网关10.10.10.2发起ping测试，在导航栏"监控\>安全日志\>单包攻击日志"中，可以看到在防火墙上生成单包攻击日志。

![](./Media//image7.png)


客户端可以看到所有报文ping请求超时，说明ping包触发防火墙的攻击防范策略，超过了每个报文1000字节，全部被丢弃。据此可以验证攻击防范配置生效。

![](./Media//image8.png)


**说明：**

1、本实验用的模拟器为F1060，设置内存为默认。（F1090配置同理）

2、Windows系统自带的防火墙会影响网卡收发报文，务必先关闭Windows
Defender防火墙。

3、IE代理会拦截Web界面，使用防火墙Web界面务必关闭IE代理。

4、攻击防范策略需要在安全域下应用才能生效。
