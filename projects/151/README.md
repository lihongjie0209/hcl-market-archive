**标签：**

RBM

VRRP

NAT

**需求：**

防火墙FW1和FW2作为网络出口进行HA组网，RBM结合VRRP，同时需要两台防火墙同时处理业务，提高业务处理能力。但是当FW1或其链路发生故障时，FW2可以接替FW2继续工作，保证业务不会中断。

**实验步骤：**

1.  防火墙配置

    a.  FW1

        i.  根据组网规划，配置接口的IPV4地址

        ii. 接口加入安全域，配置安全策略

        iii. 配置静态路由，保证网络可达

        iv. 配置高可靠性

            1.  RBM部分

            2.  VRRP部分

        v.  配置接口NAT

    b.  FW2

        i.  根据组网规划，配置接口的IPV4地址

        ii. 接口加入安全域，配置安全策略

        iii. 配置静态路由，保证网络可达

        iv. 配置高可靠性

            1.  RBM部分

            2.  VRRP部分

        v.  配置接口NAT

2.  交换机配置

    a.  SW3

        i.  根据组网规划，配置接口的IP地址

    b.  SW4

        i.  根据组网规划，配置接口的IP地址
