# 工程名称
通过在AP上手工指定AC IP地址建立三层CAPWAP隧道配置举例


## 需求：
AP通过交换机与AC相连，跨三层路由可达。 
需要实现AP能正常在AC上注册在线，具体要求如下：
AC属于VLAN 100，AP属于VLAN 200，AC和AP之间跨三层网络建立连接，AP手工自定自己的IP地址，并通过wlan ac ip xxx指定要上线的AC，随后去AC上线。 


## 实验步骤：
1、AC上配置IP地址和路由信息 
# 
 ip route-static 0.0.0.0 0 192.168.1.1 
# 
  
2、在交换机上配置vlan 100和200的网关 
  
3、在AP上手动配置静态IP地址，指定AC的IP地址和默认路由，并保存配置 
# 
 ip route-static 0.0.0.0 0 192.168.2.1 
# 
 wlan ac ip 192.168.1.100 
#
