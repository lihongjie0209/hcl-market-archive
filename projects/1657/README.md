# 内网用户通过NAT地址访问外网配置举例（静态地址转换）

**标签：**

**NAT**

## 需求

内部网络用户10.110.10.8/24使用外网地址202.38.1.100访问Internet。

## 实验步骤：

1、按照组网图配置各接口的IP地址。

2、配置内网IP地址10.110.10.2到外网地址202.38.1.100之间的一对一静态地址转换映射。

nat static outbound 10.110.10.2 202.38.1.100

使配置的静态地址转换在接口GigabitEthernet1/0/2上生效。

\#

interface GigabitEthernet0/1

ip address 202.38.1.1 255.255.255.0

nat static enable

\#
