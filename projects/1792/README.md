# 工程名称

防火墙做七层负载SSL双向代理

## 需求：
过防火墙负载内部HTTPS服务器，并且做双向代理。

防火墙1模拟LB，防火墙2和3模拟HTTPS服务器，外网PC访问模拟客户端。
地址分别为FW1 1.1.1.2/24 2.2.2.2/24 .3.3.3.2/24

FW2 2.2.2.1/24
FW3 3.3.3.1/24
终端1.1.1.1/24

## 实验步骤：

1.配置IP和路由，注意PC上也需要加路由到虚服务地址。

2.配置安全策略和安全域，外网口放入untrust，内网口放入trust，由于七层负载属于代理，因此策略都是untrust-local和local-trust。

3.配置实服务器。实服务组和虚服务器。

4.导入证书，创建PKI域和SSL服务器策略、SSL客户端策略。

5.虚服务器下调用SSL服务器策略和客户端策略。

6.配置FW2和FW3，策略全通，放安全域，开启http和https服务。
