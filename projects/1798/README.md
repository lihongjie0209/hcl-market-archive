## 需求：

1.  Device A与Device
    B通过各自的三层以太网接口GigE1/0/1～GigE1/0/3相互连接；

2.  在Device A和Device
    B上分别配置三层动态链路聚合组，并为对应的三层聚合接口配置IP地址和子网掩码。

## 实验步骤：

1)  配置Device A

    A.  \#
        创建三层聚合接口1，配置该接口为动态聚合模式，并为其配置IP地址和子网掩码。

    B.  \# 分别将接口GigE1/0/1至GigE1/0/3加入到聚合组1中。

2)  配置Device B

> Device B的配置与Device A相似，配置过程略。
