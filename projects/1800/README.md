## 需求：

1.  Device A与Device
    B通过各自的三层以太网接口GigE1/0/1～GigE1/0/4相互连接；

2.  在Device A和Device
    B上分别配置两个三层静态链路聚合组，并为对应的三层聚合接口都配置IP地址和子网掩码；

3.  通过在聚合组1上按照源IP地址进行聚合负载分担、在聚合组2上按照目的IP地址进行聚合负载分担的方式，来实现数据流量在各成员端口间的负载分担。

## 实验步骤：

1)  配置Device A

    A.  \#
        创建三层聚合接口1，配置该接口对应的聚合组内按照源IP地址进行聚合负载分担，并为其配置IP地址和子网掩码。

    B.  \# 分别将接口GigE1/0/1和GigE1/0/2加入到聚合组1中。

    C.  \#
        创建三层聚合接口2，配置该接口对应的聚合组内按照目的IP地址进行聚合负载分担，并为其配置IP地址和子网掩码。

    D.  \# 分别将接口GigE1/0/3和GigE1/0/4加入到聚合组2中。

2)  配置Device B

> Device B的配置与Device A相似，配置过程略。
