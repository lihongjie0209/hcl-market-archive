# VRRP+STP配置举例

## 需求：

网络中SW1和SW2分别作为下游设备网关，配置VRRP。为实现链路级冗余，SW3和SW4分别与SW1
SW2双上行互联。

##  实验步骤：

1.  互联接口ip配置

2.  创建多个vrrp组

## 测试结果：

通过display vrrp查看vrrp状态，其中vlan 600可以正常选出主备，而vlan
500不能正常选举主备，该问题原因为sw2的3口被stp
阻塞了。1-4设备组成了8自环。不过就算被阻塞业务应该都是没有问题的，主设备挂掉也能正常走sw2的。
