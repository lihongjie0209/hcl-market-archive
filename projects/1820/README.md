# 工程名称

防火墙串联模式做负载均衡，实现自动跳转https。

## 需求：

防火墙FW1做负载均衡设备，并且能做到http自动跳转到https。
后端FW2和FW3做https服务器，地址为2.2.2.1/24和3.3.3.1/24.
FW1做LB设备并且做网关处理，vsip5.5.5.5
PC模拟客户端访问。

## 实验步骤：

1.配置地址和路由。

2.配置FW2和FW3，开启https服务，配置安全策略和安全域，策略全通。

3.配置FW1，配置实服务器，实服务组和虚服务。

4.配置健康性检测和持续性组。

5.创建PKI域，导入证书，创建SSL服务器策略和SSL客户端策略，证书参考受诫礼漏洞获取。

6.创建两个虚服务，虚服务http99用99端口来做重定向，http是真实访问的443端口。

7.PC做好路由。

## 测试结果：

由于跳转界面需要视频，此处就不贴视频了，大家可以直接用该工程测试，并且由于防火墙本身80端口可以自动跳转443，因此我此处用的是99端口来避免80自动的跳转。
实际访问可以打开即可。

## 说明： 


1.持续性选择的是地址端口，目的是方便看到负载的情况，实际登录FW2和FW3会有问题，需要改持续性为源地址。

2.99端口是为了规避80自动跳转，现网需要可以直接使用80，这样实现用户只输入域名或者IP就能自动跳转HTTPS。
