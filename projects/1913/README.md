# 工程名称

防火墙旁路模式显示HTTP重定向

## 需求：

防火墙实现负载均衡，并且防火墙配置HTTP重定向，实现客户端输入HTTP模式的地址能直接跳转到HTTPS，避免客户二次输入。
防火墙旁路模式地址为1.1.1.1/24 vsip5.5.5.5地址地址为6.6.6.6.
交换机做所有设备的网关，并且FW3和FW4做服务器，提供HTTPS服务，地址为3.3.3.1/24和4.4.4.1/24.
PC做终端模拟访问。

## 实验步骤：
1.配置IP和路由。

2.FW3和FW4配置全通策略，并且配置安全域。

3.FW3和FW4开启HTTP，HTTPS服务，并且创建本地用户。

4.配置持续性和健康性检测模板。

5.配置实服务器，实服务组和虚服务器。

6.导入证书创建PKI域，创建SSL服务器策略和客户端策略。

7.配置安全策略和安全域，放通local-trust和trust-local。

8.PC上配置IP。
