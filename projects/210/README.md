# FTP服务器典型配置举例

## 需求：

-   FTP客户端登录FTP服务器的用户名为admin，密码为Qwerty1234。

-   将存储在PC上的文件temp.bin上传到FTP服务器，并使用FTP功能备份FTP-Server的启动配置文件。

## 实验步骤：

实验步骤：

1、配置接口IP地址，保证网络可达；

2、开启Router的FTP服务器功能；

3、创建本地FTP用户。

## 测试结果：

用户向Router发起FTP连接，在FTP客户端按照提示输入用户名admin及正确的密码后，可成功登录Server，实现上传或下载文件。
