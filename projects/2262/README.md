# 工程名称

防火墙做负载均衡，并且实现七层的V4转V6。

## 需求：
防火墙做负载均衡功能，映射HTTPS服务器，并且能实现V4访问V6网络。

FW1做LB，地址如图。

FW2和FW3做HTTPS服务器。

PC做终端。

交换机做所有设备网关


## 实验步骤：

1.配置地址和路由。

2.配置FW2和FW3的策略和安全域，模拟HTTPS服务器，因此策略全通。并且开启HTTPS服务。

3.配置健康性检测和持续性。

4.配置实服务器，实服务组和虚服务器，注意由于七层V4转V6，虚服务可以用V4地址，实服务器是V6的。这样不用AFT。

5.配置安全策略和安全域，由于有健康性检测，并且七层情况，因此V4策略放通外网到local、V6策略放local到内网的。

6.配置PKI域、ssl服务器策略和客户端策略，由于模拟器问题，没有HTTPS，只能做双向代理。
