# 二层聚合负载分担配置举例



## 需求：
1. Device A与Device B通过各自的二层以太网接口GigabitEthernet1/0/1～GigabitEthernet1/0/4相互连接。
2. 在Device A和Device B上分别配置两个二层静态链路聚合组，并使两端的VLAN 10通过二层聚合接口1互通、VLAN 20通过二层聚合接口2互通。
3. 通过在聚合组1上按照源MAC地址进行聚合负载分担、在聚合组2上按照目的MAC地址进行聚合负载分担的方式，来实现数据流量在各成员端口间的负载分担。


## 实验步骤：
1. 创建二层聚合接口1，配置该接口对应的聚合组内按照源MAC地址进行聚合负载分担。将GigabitEthernet1/0/1、GigabitEthernet1/0/2加入到聚合组1中，配置聚合组1允许VLAN 10的报文通过。
2. 创建二层聚合接口2，配置该接口对应的聚合组内按照目的MAC地址进行聚合负载分担。将GigabitEthernet1/0/3、GigabitEthernet1/0/4加入到聚合组2中，配置聚合组1允许VLAN 20的报文通过。
