# MPLS L2VPN静态PW配置举例

## 需求：

用户网络有若干个站点，希望通过在骨干网上建立静态PW，实现站点1与站点2互联，站点1和站点2通过以太网接口的方式接入PE。

## 实验步骤：

1.  在MPLS骨干网上配置IGP协议，实现骨干网PE和P的互通

2.  在MPLS骨干网上配置MPLS基本能力和MPLS LDP，建立LDP LSP

3.  创建交叉连接组，在交叉连接组内创建交叉连接，将内网接口与此交叉连接关联，并在交叉连接内创建静态PW，以便将AC和PW关联。
