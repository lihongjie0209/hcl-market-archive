# ICMP-echo测试配置举例

## 需求：

使用NQA的ICMP-echo测试功能，测试本端（Device
A）发送的报文是否可以经过指定的下一跳设备（Device
C）到达指定的目的端（Device B），以及报文的往返时间。

## 实验步骤：

1.  配置各接口的IP地址。

2.  配置静态路由或动态路由协议，确保各设备之间路由可达。

3.  创建ICMP-echo类型的NQA测试组，并启动探测。
