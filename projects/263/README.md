# ICMP-jitter测试配置举例

## 需求：

使用NQA的ICMP-jitter测试功能，测试本端（RTA）和指定目的端（RTB）之间传送报文的时延抖动。

## 实验步骤：

1.  配置各接口的IP地址。

2.  配置静态路由或动态路由协议，确保各设备之间路由可达。

3.  创建ICMP-jitter类型的NQA测试组，并启动探测。
