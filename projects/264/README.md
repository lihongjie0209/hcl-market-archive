# VPLS LDP方式配置举例

## 需求：

1.  CE 1、CE 2和CE 3分属于3个站点，同属于VPN 1；

2.  站点1、站点2和站点3通过以太网接口的方式接入PE 1、PE 2和PE 3；

3.  在各个PE上配置VPLS，使得PE之间采用LDP信令协议建立PW，通过PW连接各个CE。

## 实验步骤：

1.  在MPLS骨干网上配置IGP协议，实现骨干网PE和P的互通

2.  在MPLS骨干网上配置MPLS基本能力和MPLS LDP，建立LDP LSP

3.  创建虚拟交换实例，并配置远端PE，

4.  内网接口与虚拟交换实例关联。

## 测试结果：
