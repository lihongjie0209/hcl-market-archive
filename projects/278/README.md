# NAT444端口块动态映射配置

## 需求：

内部网络中的10.110.10.0/24网段的用户可以访问Internet，其它网段的用户不能访问Internet。

基于NAT444端口块动态映射方式复用两个外网地址202.38.1.10和202.38.1.11，外网地址的端口范围为1024～65535，

端口块大小为300。当为某用户分配的端口块资源耗尽时，再为其增量分配1个端口块。

## 实验步骤：

1、配置接口地址及相关路由

2、Router设备上配置地址组0，包含两个外网地址202.38.1.2和202.38.1.3，外网地址的端口范围为1024～65535，端口块大小为300，增量端口块数为1

3、配置nat outbound
