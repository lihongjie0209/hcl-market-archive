# NAT444端口块静态映射配置

## 需求：

内部网络用户10.110.10.1～10.110.10.10使用外网地址202.38.1.100访问Internet。

内网用户地址基于NAT444端口块静态映射方式复用外网地址202.38.1.100，

外网地址的端口范围为10001～15000，端口块大小为500。

## 实验步骤：

1、配置接口地址及相关路由

2、配置端口块组，添加私网地址成员，添加公网地址成员，配置端口块大小，端口范围

3、配置接口上nat端口块静态映射
