# OSPF虚连接配置举例（交换）

## 需求：

Area 2与Area 0没有直接相连。Area 1被用作传输区域（Transit
Area）来连接Area 2和Area 0。SWB和SW
C之间配置一条虚连接。配置完成后，SWB能够学到Area 2中的路由。。

##  实验步骤：

1.  配置各接口的IP地址；

2.  配置OSPF，建立OSPF邻居关系；

3.  配置虚连接；
