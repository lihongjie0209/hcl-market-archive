# OSPF引入自治系统外部路由配置举例交换

## 需求：

所有的交换机都运行ospf，整个自治系统划分为3个区域，其中SWA和SWB作为ABR来转发区域之间的路由，在SWC上配置为ASBR引入外部路由（静态路由），且路由信息可正确在AS内传播。

##  实验步骤：

1.  配置各接口的IP地址；

2.  配置OSPF，建立OSPF邻居关系；

3.  配置引入自治系统外部路由。
