# LDP PW配置举例

## 需求：

用户网络多个站点之间通过静态PW实现互通，在PE 1和PE
2分别创建以太网服务实例10，匹配接口Twenty-FiveGigE1/0/1接收到的VLAN
Tag为10的报文。

##  实验步骤：

1.  在交换机上配置路由协议，使得各交换机的接口IP地址（包括Loopback接口IP地址）之间路由可达；

2.  配置LSR ID、L2VPN及LDP；

3.  设备运行OSPF用于建立LSP；

4.  配置连接站点的接口，创建服务实例与交叉连接关联，并在交叉连接内创建LDP
    PW，实现AC和PW关联。
