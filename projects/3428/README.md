# 工程名称

防火墙做RBM实现OSPF双主。
## 需求：
防火墙做RBM，并且和上下对接用OSPF，双主模式。
上下行路由器做OSPF，并且用loopback接口模拟终端访问。


## 实验步骤：
1.配置地址，信息如图。

2.路由器配置OSPF信息。

3.防火墙上配置RBM。

4.配置安全策略和安全域，并且上行放入untrust，下行放入trust。由于有OSPF，因此要放通OSPF的策略。

5.配置OSPF。
