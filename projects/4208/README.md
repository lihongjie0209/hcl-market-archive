# 工程名称
V7交换机日志外发配置


## 需求：
将交换机上产生的日志发送到内网的日志服务器192.168.1.2



## 实验步骤：
1、交换机配置ip地址，保证可以跟日志服务器通信
#
interface Vlan-interface1
 ip address 192.168.1.1 255.255.255.0
#


2、交换机开启信息中心(默认开启，防止人为关闭，建议重新开启下)配置日志主机
#
 info-center enable (默认配置，所以配置后dis cu不显示)
 info-center loghost 192.168.1.10
#


3、交换机配置发送日志时使用的源地址(建议配置，非必配项。这里无法指定具体ip，可以指定对应接口，设备会使用接口ip作为源发送)
#
 info-center loghost source Vlan-interface1
#


## 测试结果：
日志服务器侧可以收到交换机发送的日志信息，本工程中只是展示交换机侧配置，logserver未作配置


## 说明： 
1、交换机和日志服务器之间基础通信要正常，syslog默认使用udp的514端口

2、建议在防火墙上指定发送日志时指定发送日志使用的ip地址，同时日志服务器上配置该ip作为设备的ip
