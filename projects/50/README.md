# 动态分配IPv6地址配置举例

## 需求：

Switch作为DHCPv6服务器，DHCPv6客户端从DHCPv6服务器获取IPv6地址前缀，以及网络配置参数：DNS服务器地址、域名、SIP服务器地址和SIP服务器域名。

##  实验步骤：

1.  配置DHCPv6服务器

2.  配置地址池和前缀池

3.  配置为客户端分配的DNS服务器地址、域名及DSIP服务器地址、域名

4.  接口使能dhcpv6服务器模式
