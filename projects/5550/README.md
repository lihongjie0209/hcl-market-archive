# 工程名称
静态黑名单配置举例


## 需求：
需要对接入无线网络的终端进行接入限制，仅静态黑名单中的终端被拒绝接入。
如图1所示，AC和AP通过Switch相连，AP已上线，要求配置静态黑名单，仅拒绝MAC地址为00e0-0402-1235的终端接入，允许其它终端接入。
![组网图](./Media/黑名单.png) 


## 实验步骤：
用wlan static-blacklist mac-address mac-address 命令来添加静态黑名单表项。

[AC]wlan static-blacklist mac-address 00e0-0402-1235


## 测试结果：
(1) 在AC上可以查看终端已经被加入黑名单。
![黑名单结果](./Media/企业微信截图_20221021200343.png) 


(2) MAC为 00e0-0402-1235的终端尝试接入该无线网络，接入失败，而其它终端可以成功上线。

## 说明： 
配置静态黑名单后，名单中的客户端将不允许上线，如果静态黑名单中的客户端在线，设备会解除与该客户端的关联。undo wlan static-blacklist命令中，如果未指定本参数，则表示将静态黑名单中所有客户端从静态黑名单中删除。
同一个客户端不能同时存在静态黑名单和白名单中。
黑名单的MAC地址不能设置为组播或者广播地址。
