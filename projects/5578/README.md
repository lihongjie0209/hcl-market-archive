# 工程名称
通过if-match将AP根据获取的IP地址网段加入AP组


## 需求：
AC连接L3交换机，L3交换机连接三个AP，三个AP分别获取vlan 200，300和400网段的地址，根据AP获取的IP地址段，利用if-match匹配规格让AP自动加入不同的AP组。


## 实验步骤：
【组网图】

![1](./Media/图片1.png) 

1. 在AC上分别配置三个AP组，通过if-match指定AP根据获取的IP地址网段自动加入不通的AP组；
2. 在L3交换机上分别配置三个IP地址段，对应配置三个DHCP地址池，提供三个不同网段的IP地址；
3. 连接L3交换机三个接口的AP分别配置为access口，打上不通PVID，让连接的三个AP获取不通网段的IP地址；
4. 三个AP获取不通网段IP地址并在AC上线后，根据if-match规则，分别加入不同AP组并获取相应的配置。
