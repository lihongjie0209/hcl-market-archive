# 工程名称
DHCPv6中继配置举例

## 需求：
DHCPv6客户端所在网络地址为1::/64，DHCPv6服务器的地址为2::2/64。客户端和服务器不在同一个链路范围，需要通过DHCPv6中继转发报文。

1. AC作为DHCPv6中继，为客户端和服务器转发报文。

2. AC同时作为1::/64网络的网关设备，通过RA消息中的M标志位和O标志位指定该网络中的主机通过DHCPv6获取IPv6地址和其他网络配置参数。


## 实验步骤：
组网：

![1](./Media/图片1.png) 

【AC配置】

1. 配置VLAN接口2和VLAN接口3的IPv6地址。取消设备发布RA消息的抑制。配置被管理地址的配置标志位为1，即主机通过DHCPv6服务器获取IPv6地址。配置其他信息配置标志位为1，即主机通过DHCPv6服务器获取除IPv6地址以外的其他信息；
2. 配置VLAN接口3工作在DHCPv6中继模式，并指定DHCPv6服务器地址（位于SWA上）；
3. AC连接交换机的端口配置为access vlan 2，连接三台AP的端口配置为access vlan 3。

【交换机配置】

1. 在交换机上配置int vlan 2接口的IPv6地址为2::2/64，DHCPv6服务器网段为2::/64；
2. 配置静态路由指向1::0/64网段（ipv6 route-static 1:: 64 2::1）。

## 测试结果：
1. 测试AC上注册AP及其获取的IPv6地址；
2. 测试SWA ping AP的IPv6地址可通；
3. 在AC上查看DHCPv6中继的相关报文统计信息。
