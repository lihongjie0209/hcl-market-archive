# 工程名称
通过https登录AC设备典型配置举例


## 需求：
Host和设备通过IP网络相连且路由可达。管理员可以通过Host使用HTTPS方式登录设备，以便通过Web页面来配置和管理设备。


## 实验步骤：
1、AC上开启https功能
2、AC上配置web用户名为admin，认证密码为h3c123456789，服务类型为https
3、连接本地host主机，配置与AC同网段的ip地址192.168.1.11

![1](./Media/1.png) 


## 测试结果：
在PC的浏览器地址栏内输入设备的IP地址并回车，浏览器将显示Web登录页面。

![2](./Media/2.png) 

在Web登录页面输入用户名及密码，点击<登录>按钮后即可登录，显示Web初始页面。成功登录后，用户可以在配置区对设备进行相关配置。
