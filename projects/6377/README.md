# 工程名称

H3C无线控制器通过Radio进行ACl接入控制配置举例

## 需求：

在AP的Radio下配置ACL，实现对无线客户端的接入控制。

## 实验步骤：


1.配置AC的接口

2.配置Switch的接口

3.配置二层ACL，并指定permit、deny规则

4.配置无线服务模板

4.配置AP，使AP注册上线，释放无线信号，开启ACL接入控制功能



## 测试结果：
ACL下deny的终端无法接入无线，permit的终端可以接入无线
