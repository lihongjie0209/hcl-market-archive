# 公私网路由互引组网配置举例

## 需求：

传统组网中，需要公私网路由互引打通，但是仅私网有VPN，公网没有VPN。

##  实验步骤：

1.  配置SW1、SW2以及SW3的各接口的ip地址；

2.  配置SW1和SW3的静态路由，打通两台设备的路由；

3.  在SW2用静态路由和路由复制打通公私网路由；

4.  测试网络连通性。
