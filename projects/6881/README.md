# 工程名称
AP功信配置举例


## 需求：
AP通过Switch与AC连接，具体要求如下：
· 通过配置修改AP radio1的信道，默认为自动信道，将radio1修改为固定信道149；


## 实验步骤：
1、配置AP上线成功。

2、在AP的radio1射频口下配置信道为149。

## 测试结果：
通过display wlan ap all radio命令查看AP radio1的默认信道为52。
