# OSPF FA地址填充规则配置举例

## 需求：

SW1,SW2,SW3,三台交换机通过一台纯二层交换机S6850互连，三台设备的互连接口处于同一网段10.1.1.0/24，SW2和SW3相连网段为20.1.1.0/24，SW3上有2个loopback口模拟外部网段。在SW1和SW2之间启用OSPF协议属于区域area0，在SW2上配置2条静态路由学习loopback口上的外部网段，配置去往100.1.1.1的下一跳为10.1.1.3，去往100.1.1.2的下一跳为20.1.1.2。查看fa地址填充规则。
