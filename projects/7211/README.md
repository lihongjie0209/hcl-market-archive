# OSPF FA地址作用配置举例

## 需求：

SW1,SW2,SW3,三台交换机通过一台纯二层交换机S6850互连。在SW1和SW2之间启用OSPF协议属于区域area0，在SW2上配置2条静态路由学习loopback口上的外部网段。

本实验验证FA不为零，域内设备访问外部网段将直接选取到达FA的最短路径，不经过ASBR而选取最优路径。
