# 工程名称
AP功率配置举例


## 需求：
AP通过Switch与AC连接，具体要求如下：
· 通过配置修改AP radio1的功率值，默认为20，将5G修改为10dBm；


## 实验步骤：
1、配置AP上线成功。

2、在AP的radio1射频口下配置功率值为10dBm。

## 测试结果：
通过display wlan ap all radio命令查看AP radio1的默认功率为20dBm。

![xindao1](./Media/企业微信截图_16685796107965.png) 

修改AP的功率为10dBm,通过命令查看功率已经修改成功。
