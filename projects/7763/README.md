# 工程名称
AP频宽配置举例


## 需求：
AP通过Switch与AC连接，具体要求如下：
· 通过配置修改AP radio1的频宽，默认为80MHz，将5G修改为40MHz；


## 实验步骤：
1、配置AP上线成功。

2、在AP的radio1射频口下配置频宽为40MHz。

## 测试结果：
通过display wlan ap all radio命令查看AP radio1的默认频宽为80MHz。

修改AP的频宽为40MHz,通过命令查看频宽已经修改成功。
