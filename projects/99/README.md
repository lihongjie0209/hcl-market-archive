# LDP方式VPLS配置举例

## 需求：

PE 1、PE
2通过服务实例将报文与VSI实例关联，以便更为灵活地匹配从AC接收到的报文：服务实例10用来匹配接口收到的VLAN
Tag为100的报文，并通过VSI实例aaa转发文。

##  实验步骤：

1.  在交换机上配置路由协议，使得各交换机的接口IP地址（包括Loopback接口IP地址）之间路由可达；

2.  配置公网隧道；

3.  配置LDP信令协议建立PW隧道；

4.  配置连接站点的接口，绑定VSI实例。

verbose命令，可以看到建立了两条PW，状态为up。。以PE1为例：
